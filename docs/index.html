What this is

AI Job Search is a structured workflow that turns Claude Code into a full-stack job application assistant. It helps you move from an empty profile to tracked application results with a clear process: evaluate fit, draft materials, verify the outputs, and prep for interviews.

How /apply works

1. Parse

Reads the job posting or URL and extracts the key requirements.

2. Evaluate fit

Scores the role against your profile, experience, and constraints.

3. Draft

Generates a tailored CV and cover letter in a controlled workflow.

4. Review + revise

Runs a reviewer pass to catch gaps and improves the final output.

5. Compile + verify

Checks PDF output quality, text extraction, and ATS-friendliness.

6. Present

Delivers the final package with a verification checklist.

Core commands

/setupBuild your profile from documents or a CV.
/scrapeSearch job portals for matching roles.
/rankScore and shortlist matches.
/applyTailor CV and cover letter to a specific role.
/interviewPrepare stage-specific interview material.
